# How to setup my application

1. Install Ruby (recommended version 3.4.7)

2. Clone the repository:
    ```bash
    git clone https://github.com/GlebGleb4444/cars_management.git
    ```

3. Navigate into the project folder:
    ```bash
    cd cars_management
    ```

4. Switch to the feature branch:
    ```bash
    git checkout feature/task-2-add-total-requests-logic
    ```

5. Run the application:
    ```bash
    ruby index.rb
    ```

6. Follow the prompts in the console to search and sort cars.
